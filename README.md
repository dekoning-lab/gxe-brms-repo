# Bayesian gene–environment interactions in infant attachment

Reproducibility repository accompanying:

> Potter-Dickey, A., Letourneau, N., & de Koning, A. P. J. *Bayesian Evidence
> for Modest Effects of Individual Genes and Parenting on Infant Attachment
> Security.* [TODO: journal] (2026).

This repository contains the complete Bayesian analysis pipeline used in
the paper: data harmonization, multiple imputation, hierarchical Bayesian
ordinal regression in `brms`, model comparison via approximate
leave-one-out cross-validation, prior sensitivity, MCMC diagnostics, and
all tables and figures of the main manuscript. It is designed both as
(a) a reference implementation of the modelling approach for any
similarly-structured cohort study, and (b) a reproducibility platform
that regenerates the paper's main results from the original APrON cohort
data.

## Data availability

The real APrON cohort dataset used in the paper contains identifiable
maternal–infant dyad information and is **not redistributable** under
the cohort's REB constraints. Researchers with appropriate IRB/REB
approval can request access from the APrON Study Team (see
`docs/DATA.md`).

To allow the pipeline to be inspected, run end-to-end, and adapted to
other cohorts, this repository ships with a **synthetic dataset**
generated by [`scripts/synthetic/00_generate_synthetic_data.py`](scripts/synthetic/00_generate_synthetic_data.py).
The synthetic dataset preserves the marginal distributions of each
variable and the overall missingness pattern but uses fresh participant
IDs and contains **no individual-level information** from the real
cohort. It is suitable for verifying the pipeline mechanics; the
posterior summaries it produces are **not scientifically meaningful**.

## Reproducing the paper's main results

With access to the real input file
`Fulldata_with_PCs_and_maternal_PCs.txt` (placed at `data/`), the full
pipeline reproduces:

- **Table 1** — primary coefficient estimates with 95% credible intervals
- **Table 2** — prior sensitivity analysis
- **Figure 2** — posterior density panels
- **Figure 3** — directional Bayes-factor evidence calibration
- **Figure 4** — predicted-probability plots for the three strongest signals
- All supplementary tables and figures referenced in the main paper

See [`docs/pipeline.md`](docs/pipeline.md) for the exact command
sequence.
