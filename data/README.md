# Data directory

The pipeline reads its input from this directory. See
[`../docs/DATA.md`](../docs/DATA.md) for the full schema.

## Files

| File | Source | In repository? |
|---|---|---|
| `Fulldata_with_PCs_and_maternal_PCs.txt` | APrON cohort + ancestry PCs | No — must be supplied separately or replaced by the synthetic dataset |
| `Kobor_lab_genotype_summary_5HTTLPR_triallelic.xlsx` | UBC Kobor lab triallelic genotype calls (used only for Phase 8) | No — request from APrON |
| `imputed_datasets_for_brms_m100.rds`      | Generated by `04_run_mice_imputation.R`  | No (output) |
| `imputed_datasets_for_brms_m100_v2.rds`   | Generated by `45_augment_imputed_data.R` | No (output) |
| `mice_imputed_m100_maxit30.rds`           | Generated by `04_run_mice_imputation.R`  | No (output) |
| `synthetic/Fulldata_synthetic.txt`        | Generated by `scripts/synthetic/00_generate_synthetic_data.py` | Yes |

## Using the synthetic data

```bash
python3 ../scripts/synthetic/00_generate_synthetic_data.py
cp synthetic/Fulldata_synthetic.txt Fulldata_with_PCs_and_maternal_PCs.txt
```

Then run the pipeline as in `docs/pipeline.md`. The synthetic data has
n=210 rows with `DUMMY-NNNNN` IDs and approximately matches the
marginal frequencies of the real dataset's analysis variables; it
will produce posteriors that **do not correspond to any real
biological signal**.
